# Lab project moves

Made Nov 5, 2026, in the planning Project.

| Decision | Reason |
| --- | --- |
| DorkGraphs is a lab project: an Instagram brand of daily data visualizations of the American experience | It is the lab's first agentic brand, which tests the mission's question of how far an agent-supported company can go. Its repo already lives in the `unclebuckslab` org |
| DorkGraphs' character is a dork data scientist, a nerdy computer guy, not a wizard | Gives the brand its own voice without overlapping Uncle Buck or the parked music brand |
| Uncle Buck stays the overarching persona: the founder, above every project character | Project characters can come and go; the lab's voice stays one person |
| The music prediction brand stays parked and launches later under an adjusted scope that doesn't overlap DorkGraphs or Uncle Buck | Its original wizard concept collided with the other characters |
| The AI Money Report repo moves to the `unclebuckslab` org and stays private. Transferred Nov 5 | It is the lab's top-priority project. Actions use was about 344 minutes in its first 8 days, during a build week, which projects under the 1,500-minute monthly upgrade threshold |
| The Denver dashboard repo stays in the founder's personal account for now and moves later | Outside reviewers are using its current URL, and a transfer changes the Pages address with no redirect |
| The org allows GitHub Actions to create pull requests; the default workflow token stays read-only | The AI Money Report's issue drafts arrive as pull requests. Every workflow declares its own narrow permissions |
