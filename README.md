# Uncle Buck's Laboratory: HQ

How the lab runs. This repo holds the rules, standards and records behind every project from Uncle Buck's Laboratory: what gets published, how the agents work, what needs a human's sign-off, and where everything lives.

It's public on purpose. The lab's first principle is to show the work, and that includes the operating manual.

- Start here: [INDEX.md](INDEX.md)
- Projects: [registry/projects.yaml](registry/projects.yaml)
- Decisions: [decisions/](decisions/)

Uncle Buck is the founder's online persona. The lab rats are AI agents, mostly Claude. A human approves everything that goes public.
