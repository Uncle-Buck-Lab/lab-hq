# The site shows live work only

Made Nov 11, 2026, in the planning Project. Changes part of `2026-11-10-site-and-newsletters.md`.

| Decision | Reason |
| --- | --- |
| The site shows only projects with status `live`. Nothing in progress appears on it | The site presents finished work |
| No "In the lab" framing, status badges or stage trackers on the site. Those labels stay internal, in the registry and Lab Desk | The founder doesn't want the lab framed around unfinished work in public |
| Work in progress is covered in the lab dispatch, not on the site | Keeps learning in public, in the place built for it |
| A project goes on the site by setting its registry status to `live` | One switch, no site edits; the AI Money Report flips at launch |
