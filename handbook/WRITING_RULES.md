# Writing rules: five things lab writing never does

Everything published under the brand, by the founder or by an agent, is checked against these five before it ships. The Editor runs the check; the founder has the final say. Each project's voice file points here.

## 1. Throat-clearing and recaps

Openers that announce what's coming ("In today's fast-moving world," "Let's dive in") and closers that repeat it ("In conclusion," "Ultimately," "At the end of the day").

**Fix:** start with the point and stop when it's made.

## 2. Filler that sounds careful

Intensifiers and hedges that carry no information: "truly," "incredibly," "genuinely," "it's important to note," "arguably," "a wide range of."

**Fix:** delete the word. If the sentence fails without it, the claim needs evidence, not an adverb.

## 3. Buzzwords where a fact should be

"Game-changer," "unlock the potential," "navigate the landscape," "plays a crucial role," "robust," "seamless," "delve," "tapestry."

**Fix:** put a number, name, date or example in its place. If there isn't one, cut the sentence.

## 4. Fake-profound framing

"It's not just X, it's Y." "Here's the thing." A rhetorical question answered in the next line. A one-line paragraph to land every point.

**Fix:** state the claim once, plainly.

## 5. Mechanical rhythm and decoration

Everything grouped in threes, an em-dash aside in every paragraph, bold scattered through the text, emoji, bullets standing in for an argument.

**Fix:** vary sentence length, keep lists for parallel items, bold at most once per section.

## How the check runs

- Before review, the Editor marks every hit in the draft and proposes the fix.
- From milestone M3, an automated check plus a model judge run in the pre-publish skill, scored against a gold set of examples in `evals/`.
- A draft that fails goes back before it reaches the founder.
