# Founding decisions

Made Nov 3, 2026, in the planning that produced Operating Plan v1.0. Each line is a decision and its reason. A decision isn't reopened without a new reason; a change gets a new dated file.

## Identity

| Decision | Reason |
| --- | --- |
| The name is **Uncle Buck's Laboratory**, with the apostrophe | The lab belongs to Uncle Buck, so it's possessive. "Laboratory" covers research, experiments and building, and pairs with the lab-rat cast |
| One master brand; each project keeps its own name with "from Uncle Buck's Laboratory" | With no audience yet, all attention should build one name. Projects earn their own brand once they have their own audience |
| Handle `unclebuckslab` everywhere; site at `unclebuckslab.com` | Free on nearly every platform on Nov 3; fits X's 15-character limit, which `unclebuckslaboratory` doesn't |
| Uncle Buck is the founder's openly disclosed persona; the agents are his lab rats | The persona carries the voice; the About page connects the work to the person |
| Lab projects: AI Money Report, Congress Cards, Denver Neighborhood Sales, Field Notes; a music prediction brand is parked | These are the projects that fit the lab. Everything else the founder builds stays personal |

## How the lab runs

| Decision | Reason |
| --- | --- |
| Stack: GitHub (repos, Actions, Pages, Issues, Projects), Claude Code and Claude Projects | It already runs four scheduled products at $0. Adopt tools when they solve a problem the lab actually has |
| Linear, Notion and n8n are deferred, each with a trigger | Linear: the board passes about 150 open items or cross-project planning costs time weekly. Notion: someone non-technical needs to edit lab docs. n8n: three or more workflows need to move data between non-GitHub services |
| GitHub org on the Free plan | Public repos don't use Actions minutes and Pages hosts them free. Upgrade if private-repo Actions use regularly passes about 1,500 minutes a month, or a second person joins |
| lab-hq and lab-site are public; lab-desk is private | "Show the work" applies to the operating manual. Briefings, spend and private plans stay private |
| Time is tracked as total focus hours per milestone, estimated vs actual, with no weekly pace or calendar dates | Hours are what the founder controls. Estimates get recalibrated against logged actuals |
| Three approval tiers: pre-authorized, batched weekly, explicit | Keeps review from becoming the lab's speed limit while every public or money action still gets a human yes |
| One home for each kind of information; tools read handbook files by link | Uploaded copies go stale |
| The five writing rules replace the longer anti-slop guide | Five rules get followed; a long guide gets skimmed |
| Agents: eval gates, a hard read/act boundary, scheduled headless runs that only open issues and PRs, a provenance record behind every claim | Autonomy is only useful if it's trustworthy and safe from prompt injection |
| A shared cross-project entity database is not built for now | Not worth the upkeep yet. Revisit if Congress Cards and the AI Money Report both end up maintaining their own lobbying data |
| Lab work is fully separate from the founder's day job | No conflicts, no borrowed data, nothing to untangle later |

## Going public and money

| Decision | Reason |
| --- | --- |
| Launch with the site, AI Money Report issue 001 and the Denver dashboard together | A site with nothing to point at gets no attention |
| Email signup and analytics from day one | The list is the asset that compounds; numbers inform every later money decision |
| Nothing is sold at launch; streams start on triggers set in advance | Patience on money, speed on going public |
| Public-good projects stay free; build kits (MD files, templates, skills) can be paid | Civic work loses its point behind a paywall. The kits are the most on-brand product the lab has |
| Money rules written before the first dollar, including a holdings disclosure and a trading blackout around each report issue | The persona is openly buyable, so the limits have to be explicit and public |
| A Washington LLC is formed before any money comes in or Congress Cards publishes profiles | Separates liability and money from the founder personally; profiles of named politicians carry legal exposure |
